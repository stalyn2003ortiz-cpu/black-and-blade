## 📌 Descripción

Black & Blade es un sitio web moderno y responsive diseñado para una barbería masculina.

El objetivo principal del proyecto es presentar los servicios de la barbería y facilitar que los clientes puedan solicitar una reserva directamente mediante WhatsApp.

El sitio fue desarrollado desde cero utilizando HTML, CSS y JavaScript, con especial atención al diseño visual, experiencia de usuario, responsive design y animaciones.

---

## ✨ Características

- Diseño responsive para computadoras, tablets y dispositivos móviles.
- Navegación adaptada a dispositivos móviles.
- Sección principal tipo Hero.

- Estadísticas del negocio.
- Catálogo de servicios y precios.

- Integración con WhatsApp.
- Mensaje de reserva generado automáticamente.

- Animaciones al hacer scroll.

- Diseño visual moderno y minimalista.
- Favicon personalizado.
- Optimización básica para motores de búsqueda (SEO).

📱 Reserva mediante WhatsApp

El formulario de reserva permite al usuario seleccionar:

Nombre
Servicio
Fecha
Hora

Al enviar el formulario, JavaScript genera automáticamente un mensaje personalizado y abre WhatsApp para que la barbería pueda confirmar la disponibilidad.

🎨 Diseño

El diseño utiliza una estética masculina, elegante y minimalista, utilizando principalmente tonos oscuros y detalles dorados.

La interfaz fue pensada para transmitir una identidad premium y mantener una navegación sencilla para el usuario.

📱 Responsive Design

El sitio fue desarrollado para adaptarse a diferentes tamaños de pantalla:

💻 Desktop
📱 Mobile
📲 Tablet

La navegación, galería, servicios, formulario y demás secciones se reorganizan automáticamente dependiendo del tamaño de pantalla.
